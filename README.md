# ACE

ACE is Marcus Hendricks's private AI chief-of-staff and executive operating system.

This repository contains the working ACE application: a mobile-first command center for priorities, projects, decisions, memory, approvals, and connected systems.

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Current status

The first MVP uses local persistent data and deterministic demo intelligence. The architecture is prepared for OpenAI, Gmail, Google Calendar, Google Drive, Contacts, finance, and e-signature integrations.
